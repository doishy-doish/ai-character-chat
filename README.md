# AI Character Chat

A browser-based AI chat experience focused on conversation flow, roleplay-style interaction, and polished user experience.

## Overview

AI Character Chat is a lightweight conversational product designed to explore how browser-based AI experiences feel in practice. The project focuses on a clean UI, responsive interactions, and a strong conversational user experience.

## What It Shows

- Chat UI / frontend product design
- AI conversation flow design
- Browser-based app development
- Interactive UX patterns
- AI product experimentation in a lightweight, accessible format

## Key Features

- Character-style chat experience
- Clean and responsive interface
- Conversation-focused design
- Simple, product-first UX implementation
- AI-powered interaction loop

## Tech Stack

- JavaScript
- HTML / CSS
- Browser-based UI logic
- AI API integration

## Why This Matters for a CV

This project helps demonstrate:

- frontend product skills

- user-first design thinking
- browser-based AI application development
- clean implementation of interactive systems

## Run Locally

1. Clone the repository
2. Serve it locally using a lightweight static server
3. Add any required config values or API keys if needed

Example:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
